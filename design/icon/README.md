# Kavana's icon

Miso on the sill of the round window at night: the end of a focus block, from the Focus tab.

- `r1/`: round 1, six cat ideas from one brief (`BRIEF.md`), each drawn by its own designer, side by side in `round1.png`. I liked the window.
- `r2/`: round 2, four takes on the window (`BRIEF.md`, `round2.png`). I picked C, the night window.
- `final/`: the drawing (`icon.svg`, on the macOS grid) and its simpler version for 16 and 32 px (`icon-small.svg`), both made by `r2/C/gen.py`.
- `export.py` renders every size from them: see "Developing Kavana" in the docs.
