<h1 align="center">Kavana docs</h1>
<p align="center">How to use Kavana, where your data is kept, and how to run your own copy.</p>

These pages are how Kavana works, written down. It's a focus timer that checks in on you while you work, so you notice when you drift, with a kitten that grows up while you focus (a bit like Forest), and it runs in your browser with no account needed. If you're new, read "What is Kavana?" first and then Install, which gets it onto your phone, iPad or computer with the reminders on. The pages under "Using Kavana" follow a block from the Focus tab to the end, then the cats, and the ones at the bottom are for running your own server and working on the code.
