Add to Home Screen

Reminders only work from the Home Screen app.

1Tap the Share button in Safari. On some iPads it's inside the ⋯ menu.
2Tap Add to Home Screen. You may need to scroll down to find it.
3If you see Open as Web App, leave it on. Then tap Add.
4Open Chataltul from your Home Screen.

The Home Screen app keeps its own data, separate from Safari. If you have an account, sign in again there and everything comes along.

Settings

Focus

Block sites while you focus

Your kitten grows while you focus. Stop early, or leave Chataltul for more than a few seconds, and it wanders off. A pause lasts 5 minutes at most. "Count extra time" keeps a block going past its end until you tap Done.

Daily reminder

It won't ping you if you're already in a block.

Focus with friends

Notifications

Using a Focus mode like Do Not Disturb? Add Chataltul to its allowed apps (Settings app → Focus) so check-ins still come through.

Privacy

Without an account, everything stays in this browser. To send reminders while Chataltul is closed, the server holds this device's next few pings and deletes each one once it's sent. Usage counts are which features get used, never what you type.
